# Architecture Decision Records (ADRs)

This directory is the local, in-repo mirror of approved architectural
decisions for DONNA V2. It complements the **V2 Decisions Log** (Build Bible
doc 17) in Google Drive: when an approved decision changes architecture or
policy, record it here and reflect it in the Decisions Log (Build Bible doc 13
versioning rule).

ADRs are immutable once accepted. To change a decision, add a new ADR that
supersedes the old one and mark the old one `Superseded by ADR-NNNN`.

## Format

`ID / Date / Status / Decision / Reason / Alternatives / Consequences /
Affected Docs / Approver` (matching the Decisions Log's new-decision format).
